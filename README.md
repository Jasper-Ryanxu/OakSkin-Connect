# OakSkin-Connect
更实用，更简单的Minecraft皮肤站程序

## 介绍
OakSkin-Connect是由OakSkin运营者Jasper_Ryanxu（也就是作者本人）开发的一款现代化Minecraft皮肤站程序

## 特点
本项目开发初段是为了避免用户在遇到使用Blessing Skin Server中的问题

在安装Blessing Skin Server时需要`symlink` `synlink`等函数，而这些函数一般服务商是不会提供的

而OakSkin-Connect完全避免了这些问题，只需将代码放到主机中就可以使用，并且在虚拟主机环境下，OakSkin-Connect比Blessing Skin Server的能力更突出

在Blessing Skin Server中，oauth2应用默认只提供Read.Userdata这个权限，而OakSkin-Connect提供选择权限的功能，提供更强大的Oauth2授权功能和更美观的界面


## 安装步骤
在安装之前 请确保您的主机支持以下功能：
PHP 8.1+

1.在[Realeases](https://github.com/Jasper-Ryanxu/OakSkin-Connect/releases)中最新版Zip压缩包

2.将压缩包放入工作区根目录并解压

3.将运行目录设置在`/public`下

4.访问网站的/setup页，填写对应信息即可

Finally 访问网站，配置成功！
